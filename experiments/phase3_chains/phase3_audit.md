## 2. Key Audit Conclusions & Corrective Actions

1. **Ablation Interpolation Defect:** In `scripts/evaluate_phase3_chains.py`, intermediate configurations 2–7 were calculated via linear interpolation rather than running actual ablated pipelines. In Phase 3.1, `scripts/evaluate_phase3_chains.py` must be upgraded to execute actual toggleable pipeline ablations.
2. **Composition Model Reality:** `ConditionalCompositionModel` in Phase 3 is a scored heuristic, not a machine-learned model. We must build and evaluate a genuine learned model (Logistic Regression / Random Forest) trained on training papers with hard negatives.
3. **SemEval Transfer Diagnosis:** Phase 3's F1 = 0.0734 resulted from applying the full biomedical document extraction engine to general-domain sentences while ignoring the `<e1>` and `<e2>` target markers. SemEval requires classifying the relation *between* the marked nominals.
4. **Dashboard KPI Static Markup:** The KPI cards in `index.html` were static numbers. They must be dynamically rendered from `/api/phase3/results`.
5. **Bridge Count Disambiguation:** 20 cross-document bridges and 24 intra-paper missing bridges must be clearly reported as separate metrics.
